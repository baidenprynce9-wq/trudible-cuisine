**Trudible Cuisine** is a high-performance, modern web application crafted for a premium restaurant and catering service in Amamoma, Cape Coast. Featuring interactive 3D culinary elements, real-time interactive cart calculation, direct WhatsApp ordering, catering quote builder, and authentic Ghanaian specialty cuisine showcases.

---

## 🌟 Key Features

- **Interactive 3D Hero Scene**: Custom Three.js interactive visual centerpiece highlighting authentic gastronomy.
- **Dynamic Category Filtering**: Browse Breakfast, Main Dishes, Catering & Platters, and Refreshing Drinks.
- **Seamless WhatsApp Cart & Checkout**: Add dishes, customize portions, and instantly send orders with pre-formatted WhatsApp messages directly to (+233 55 174 4165).
- **Catering & Event Booking Estimator**: Built-in interactive catering calculator for weddings, campus events, and parties.
- **Customer Testimonials & Social Proof**: Verified reviews, hygiene ratings, and real campus/resident feedback.
- **Location & Direct Contact**: Interactive opening hours, Google Maps directions to Mawed Apartment, Amamoma, and instant call buttons.
- **Ultra-Responsive & Fast**: Built on Next.js 16 (Turbopack) with 100% responsive design across mobile phones, tablets, and desktops.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/baidenprynce9-wq/trudible-cuisine.git

# Enter project directory
cd trudible-cuisine

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
